# Gravity Flip
Аркадна гра для iOS. Персонаж біжить вертикальною шахтою,
а тап по екрану перемикає гравітацію: персонаж перелітає з
«підлоги» на «стелю». Мета - якомога довше оминати
перешкоди та збирати монети.

Виконавець: Кульчицький Микола, група ІК-41 (проєкт виконується самостійно).

## Користувач
Гравець, який хоче короткі ігрові сесії на 1–3 хвилини
і змагається за власний рекорд та подальше відкриття скінів.

## Основні сценарії
- Зіграти забіг і отримати рахунок
- Купити скін персонажа за зібрані монети та вибрати його
- Переглянути історію ігор і найкращий результат

## Сутності
- **Гравець** — нік, монети, куплені скіни, вибраний скін, історія ігор
- **Скін** — назва, рідкісність, ціна
- **Результат гри** — рахунок, кількість перемикань, зібрані монети, дата

## Вимоги
- Xcode 27
- iOS 17.6+
- Bundle ID: `com.nick.GravityFlip`

## Запуск
1. `git clone https://github.com/buzarig/GravityFlip.git`
2. Відкрити `GravityFlip.xcodeproj` у Xcode
3. Вибрати симулятор iPhone і натиснути Run (Cmd+R)

## Структура проєкту

```
GravityFlip/
├── Models/
│   ├── Describable.swift       — протокол для текстового опису
│   ├── GravityDirection.swift  — напрям гравітації
│   ├── SkinRarity.swift        — рідкісність і ціна скіна
│   ├── Skin.swift              — скін персонажа
│   ├── GameResult.swift        — результат забігу
│   ├── GameRun.swift           — логіка одного забігу + події
│   └── Player.swift            — гравець, покупки, історія
├── Demo/
│   └── DemoScenario.swift      — демонстраційний сценарій
└── ContentView.swift           — екран з логом сценарію
```

## Практична робота 1

### Де реалізовані конструкції Swift
| Конструкція | Де в коді |
|---|---|
| `struct` | `Skin`, `GameResult`, `GameRun` |
| `class` | `Player` |
| `protocol` | `Describable` (приймають `Skin`, `GameResult`, `Player`) |
| `enum` | `GravityDirection`, `SkinRarity` (rawValue), `RunEvent`, `PurchaseResult` (асоційоване значення) |
| `let` / `var` | `let` — незмінні дані (`Skin.name`, усі поля `GameResult`); `var` — стан, що змінюється (`GameRun.score`, `Player.coins`) |
| Властивості | збережені (`Skin.name`), обчислювані (`Skin.price`, `Player.bestResult`) |
| Методи | `GravityDirection.flip()` (mutating), `GameRun.handle(_:)`, `Player.buy(_:)`, `Player.record(_:)` |
| Ініціалізація | memberwise init у `Skin`; власний `init` з параметром за замовчуванням у `GameResult` і `Player` |
| Колекції | `Player.ownedSkins`, `Player.results`, масиви `shop` і `runs` у `DemoScenario` |
| Optional | `Player.selectedSkin: Skin?`, `Player.bestResult: GameResult?` |
| Безпечне розгортання | `if let` (найкращий результат), `guard` (`Player.buy`, `Player.select`), `??` і `?.` (`Player.summary`) |
| Умовні конструкції | `if`, `guard`, `switch` (`GameRun.handle`, `DemoScenario`) |
| Обробка колекцій | `for-in`, `enumerated()`, `filter`, `max`, `contains` |
### Технічні рішення
- **Player — клас**, бо гравець один на весь застосунок: різні екрани
  (магазин, гра, історія) мають працювати з тим самим об'єктом.
- **Skin, GameResult, GameRun — структури**, бо це дані, які безпечно
  копіювати; зміна копії не впливає на оригінал.
- **Властивості з `private(set)`**: змінювати стан можна лише через методи
  (`handle`, `buy`, `record`), тому правила гри не обійти ззовні.
- **enum замість рядків/Bool**: компілятор перевіряє, що оброблено
  всі варіанти в `switch`.

### Як перевірити сценарій
Запустити застосунок на симуляторі. `DemoScenario.run()` виконується при
появі екрана; лог показується у списку та в консолі Xcode (Cmd+Shift+Y).

Сценарій: гравець із 150 монетами купує скіни (один уже є, один купується,
на один не вистачає монет), вибирає куплений скін, грає 3 забіги, після
чого знаходиться найкращий результат і фільтруються забіги з рахунком ≥ 40.

Очікуваний результат:
```
Новий гравець → Nick: 150 монет, скін: Кубик, ігор: 0
Вже є: Кубик
Куплено: Неон (Рідкісний, 100 монет)
Не вистачає 250 монет на Привид
Вибрано скін: Неон
Забіг 1: Рахунок: 45, перемикань: 3, монет: 3, скін: Неон, гравітація в кінці: вгору
Забіг 2: Рахунок: 10, перемикань: 1, монет: 0, скін: Неон, гравітація в кінці: вгору
Забіг 3: Рахунок: 50, перемикань: 4, монет: 2, скін: Неон, гравітація в кінці: вниз
Найкращий результат: 50 очок
Забігів з рахунком ≥ 40: 2
Підсумок → Nick: 55 монет, скін: Неон, ігор: 3
```
