
# Gravity Flip

Аркадна гра для iOS. Персонаж біжить вертикальною шахтою,
а тап по екрану перемикає гравітацію: персонаж перелітає зі
«підлоги» на «стелю» і назад. Мета — якомога довше оминати
перешкоди та збирати монети.

Виконавець: Кульчицький Микола, група ІК-41 (проєкт виконується самостійно).

## Користувач
Гравець, який хоче короткі ігрові сесії на 1–3 хвилини
і змагається за власний рекорд та подальше відкриття скінів.

## Основні сценарії
- Зіграти забіг і отримати рахунок
- Купити скін персонажа за зібрані монети та вибрати його
- Переглянути історію ігор і найкращий результат

## Сутності
- **Гравець** — нік, монети, куплені скіни, вибраний скін, історія ігор
- **Скін** — назва, рідкісність, ціна
- **Результат гри** — рахунок, кількість перемикань, зібрані монети, дата

## Вимоги
- Xcode 27
- iOS 17.6+
- Bundle ID: `com.nick.GravityFlip`

## Запуск
1. `git clone https://github.com/buzarig/GravityFlip.git`
2. Відкрити `GravityFlip.xcodeproj` у Xcode
3. Вибрати симулятор iPhone і натиснути Run (Cmd+R)
